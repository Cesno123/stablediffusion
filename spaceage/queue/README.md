# Warteschlange

Hier Midjourney-Bilder (PNG/JPG) oder Animate-Videos (MP4) hochladen:
*Add file → Upload files*. Jeden Tag wird die **älteste** Datei automatisch
auf Instagram gepostet und danach nach `../posted/` verschoben.

Eigene Caption? Eine Textdatei mit gleichem Namen dazulegen
(`schiff.png` + `schiff.txt`). Sonst wird eine Caption erzeugt.

Bildformat: am besten `--ar 4:5`. Höhere Bilder (z. B. 9:16) werden mittig
auf 4:5 zugeschnitten, weil Instagram im Feed nichts Höheres annimmt.
